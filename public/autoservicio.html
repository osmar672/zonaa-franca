Ayuda y documentación

¿Cómo consultar un recibo?

  1. Inicie sesión utilizando su ID de empleado y contraseña.
  2. Seleccione el año que desea consultar.
  3. Seleccione el mes correspondiente.
  4. Seleccione el tipo de documento.
  5. Presione el botón "Buscar documentos".
  6. Revise los resultados mostrados en la tabla.

¿Cómo descargar un documento?

  1. Realice una búsqueda utilizando los filtros disponibles.
  2. Localice el documento que desea descargar.
  3. Presione el botón "Descargar".
  4. El sistema validará que tenga permisos para acceder al documento.
  5. Si la validación es correcta, se generará el archivo automáticamente.

Seguridad

Los documentos mostrados pertenecen únicamente al empleado autenticado. El sistema realiza una validación de permisos antes de permitir cualquier descarga.
